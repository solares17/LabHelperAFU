Лабораторная работа №1 - Измерение КУ и фазовых сдвигов

Для выполнения лабораторной работы ознакомьтесь с видео:

УОС-02

Рупорная антенна — Задание

Методика основана на методе замещения (компенсации). Цель — определить коэффициент усиления (КУ) исследуемой пирамидальной рупорной антенны путём сравнения с эталонной антенной известного КУ.

Рис. — Блок-схема измерительного тракта (метод замещения)

  • 1
    Геометрия
    Измерение геометрических параметров. Определить линейные размеры исследуемой пирамидальной рупорной антенны: габариты раскрыва (апертуры) в плоскостях векторов электрического (E) и магнитного (H) полей, а также длину рупора в каждой из плоскостей.
  • 2
    Расчёт
    Аналитический расчёт характеристик. По измеренным геометрическим параметрам вычислить теоретическое значение коэффициента усиления (КУ) и максимального фазового сдвига в раскрыве антенны с помощью математических моделей из теоретического раздела работы.
  • 3
    Опорный уровень
    Фиксация опорного уровня сигнала. Собрать первичную измерительную схему: ВЧ-генератор → передающая антенна с известным (эталонным) КУ; приёмная антенна → индикатор напряжённости поля. Зафиксировать опорный уровень принятого сигнала U0.
  • 4
    Компенсация
    Компенсационное измерение. Реконфигурировать тракт: исследуемый рупор → коаксиальная линия → вход аттенюатора → индикатор напряжённости. Регулируя вносимое затухание аттенюатора, уравнять текущий уровень сигнала с опорным значением U0. Зафиксировать величину затухания Lатт (дБ).
  • 5
    Результат
    Вычисление коэффициента усиления. Определить КУ исследуемой рупорной антенны алгебраическим методом из баланса мощностей:
    Gисслед [дБ] = Gэт [дБ] − Lатт [дБ]
    Сравнить полученное экспериментальное значение с теоретическим расчётом (этап 2).
